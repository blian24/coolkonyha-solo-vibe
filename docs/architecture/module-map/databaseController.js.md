# Module: databaseController.js (Database view entry point)

**Responsibility:** Orchestrator for the Database view — tab switching, data loading + render dispatch, search, bootstrap, and the global Escape-key modal handler. Imports every renderer and modal module in this folder so their `window.*` handlers are registered before any user interaction can reference them.
**Location:** `ui_design/js/controllers/database/databaseController.js`
**Depends on:** `state.js`, `renderers-master-data.js`, `renderers-orders.js`, `renderers-maintenance.js`, `renderers-email.js`, `modal-supplier.js`, `modal-product.js`, `modal-customer.js`, `modal-order.js` (side-effect import, to register handlers)
**Consumed by:** `ui_design/js/router.js` (`initDatabaseController`)

## Exports

| Name | Type | Description |
|------|------|-------------|
| `initDatabaseController()` | async function | Bootstrap: pre-fetches customers + order-count map, loads the default tab, applies the Settings extended-view toggle |
| `loadTab(tab)` | async function | Fetches a tab's data and dispatches to the matching renderer. Also imported by `modal-order.js` to refresh the Orders table after a status change — see the circular-import note in that file. |
| `window.switchTab`, `window.refreshCurrentTab`, `window.applySearch`, `window.toggleRow` | global functions | Called from `onclick` attributes generated by the renderer/view HTML |

## Key Concepts

- **Split from a single 1,185-line file** (`databaseController.js`, flat under `controllers/`) into this folder on 2026-09-04 — see `docs/.notes/future-ideas.md` i-8 (resolved) and `~/.claude/CLAUDE.md` §2 File Size & Modularity.
- **Render dispatcher:** `renderTab(tab, data)` is a private switch statement mapping tab keys to the 13 imported renderer functions across 4 domain files.
- **One intentional circular import:** this file imports the 4 modal files for their side effects; `modal-order.js` imports `loadTab` back from here. Safe because `loadTab` is only ever invoked from inside an event handler, never at module-evaluation time.

## What is NOT here

- Shared state, constants, and formatters — see `state.js`
- Table rendering logic — see `renderers-*.js`
- Modal open/close/edit/save logic — see `modal-*.js`
