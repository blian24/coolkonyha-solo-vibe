# Module: modal-order.js

**Responsibility:** Order detail/edit modal — status update (`PUT /api/orders/:id/status`), items table, history timeline, and the placeholder P.I.S.T.A. chat panel. More complex than the other three modals: it fetches its own detail payload (`order + items + history`) instead of reading from the table's `currentData`.
**Location:** `ui_design/js/controllers/database/modal-order.js`
**Depends on:** `state.js` (`API_BASE`, `customersCache`, `resolveLogoUrl`, `statusPill`, `fmtDt`, `fmtPrice`), `databaseController.js` (`loadTab`, to refresh the Orders table after a status change)
**Consumed by:** `databaseController.js` (side-effect import only, to register `window.*` handlers), `onclick` attributes generated by `renderers-orders.js`

## Exports

None — all handlers are registered on `window`: `openOrderModal`, `closeOrderModal`, `handleOrderModalBgClick`, `toggleOrderEdit`, `saveOrderStatus`, `sendOrderChat`.

## Key Concepts

- **The one intentional circular import in this folder:** this file imports `loadTab` from `databaseController.js`, which itself imports this file (as a side effect, to register the handlers above). Safe because `loadTab` is only called from inside `saveOrderStatus`, an event handler — by the time it runs, both modules have fully finished loading. See the note at the top of the file.
- Unlike the other three modals, saving here does **not** mutate an object inside `currentData` — it re-fetches the order detail payload AND calls `loadTab('orders')` to refresh the table, because `orderModalData` (from `GET /api/orders/:id`) and the Orders table's `currentData` (from `GET /api/orders`) are two separate fetches with no shared object reference.
- `renderOrderItemsModal` is named distinctly from `renderOrderItems` (the tab-level renderer in `renderers-orders.js`) to avoid confusion — they render different things (this modal's line-item sub-table vs. the flat cross-order Items tab).

## What is NOT here

- Supplier/Product/Customer modals — see the sibling `modal-*.js` files
- Orders table rendering — see `renderers-orders.js`
