# Release Notes - v0.5.0

**Release Date:** 2026-03-25
**Current Version:** 0.5.0

## New Features
- **P.I.S.T.A. (AI Agent):** Initial definition and implementation of the Proactive Intelligent System for Task Automation. P.I.S.T.A. interprets emails and chat notes, learns sender preferences, and proposes actions.
- **DBRobot (Deterministic Robot):** Core implementation for business rule enforcement, including Dual-Write and Pricing Continuity patterns.
- **Email Robot (v0):** Initial fetching mechanism from Gmail (INBOX + SENT). *Note: This component is not yet connected to the main system.*
- **Adatbázis Page:** A new dedicated UI for database management, administration, and monitoring.

## Additions to Existing Features
- **Dashboard Enhancements:** Integrated company logos and real-time operational statistics on the main Dashboard.
- **UI Design:** Introduced multiple design themes including Oceanic Dark (v1, v1.1) and Oceanic Plus v1.
- **Documentation:** Centralized UI descriptions and agent architecture documentation.

## Project Foundations (Pre-v0.5.0)
As this is the first versioned release documentation, the following core components are established foundations of the application:
- **Core Stack:** Vite-based React frontend and Node.js/Express backend.
- **Relational Data:** SQLite database with initial schema for orders, customers, and products.
- **Engineering Standards:** Established comprehensive coding standards, security-first principles, and "Atomic Documentation" rules.
- **Testing Infrastructure:** Automated Test Agent with unit, integration, and E2E test suites using a "Re-Learn" phase and in-memory SQLite sandbox.
- **Documentation:** Centralized `SOLUTION_DESIGN.md` and architecture docs for robots, agents, and testing.
- **ClickUp Integration:** Preliminary work on ClickUp MCP server and task management integration.
