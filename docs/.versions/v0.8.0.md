## What's New

### Dynamic Edit Modals for Database Viewer

The inline row-expansion drawers for the **Suppliers** and **Products** tables have been replaced with full-featured edit modals, matching the existing **Customers** modal pattern. 

- **Read-Only by Default:** Clicking on any row opens a read-only details modal overlay.
- **Toggle Edit Mode:** A pencil icon in the modal header seamlessly toggles editing mode without altering modal dimensions.
- **Direct Database Integration:** Saving edits performs a `PUT` request to update the record in `coolkonyha.db` via safe parameterized SQL UPDATE statements in `DBRobot` (`server/agent.js`), subsequently refreshing the active table row in-place.
- **UX Consistency:** Clicking the overlay background or pressing the Escape key closes any open modals safely.

### UI Design System Re-use

No CSS modifications were required. The implementation successfully leveraged the existing shared UI primitives from `oceanic-plus.css` including `.modal-overlay`, `.modal-card`, `.modal-hero`, `.modal-edit-btn`, `.edit-field`, and `.modal-save-btn`.
