# Release Notes - v0.5.1 (2026-04-09)

## English UI Migration (The "Hybrid Language Model")

This release focuses on standardizing the system interface into English while preserving the Hungarian context for all business data, user-added information, and AI conversations.

### 🧩 Hybrid Language Model
- **System Layer (English):** All menus, titles, button labels, table headers, and error messages are now in English. This provides a professional and standardized navigation experience.
- **Data Layer (Hungarian):** User-generated content such as product names, customer notes, and email summaries remains in Hungarian.
- **Formatting (Hungarian):** Date and time formats strictly follow the Hungarian standard (`YYYY. MM. DD. HH:MM:SS`) to maintain business consistency.

### 🛠 Changes

#### Frontend
- **index-db.html**: All static titles, navigation buttons, and table templates translated to English.
- **dataService.js**: Status labels (e.g., `OFFER_SENT` → `Offer Sent`) and fallback strings updated to English.
- **Localisation**: Default `toLocaleString` for dates switched to Hungarian format.

#### Backend & Database
- **coolkonyha.db**: Updated `business_status_workflow` table with English `display_name` and `description` values.
- **pista.js**: System-level alerts (like cost protection) updated to English.
- **AI Behavior**: P.I.S.T.A. maintains its "Language Mirroring" logic, responding in the language the user addresses it with.
