# Release Notes — v0.5.2

**Date:** 2026-05-01
**Type:** UI / Localization

## Summary

Completed the English UI migration for the CoolKonyha dashboard and finalized the main application entry point.

## Changes

### UI Entry Point
- `index.html` is now the main application entry point (Oceanic Plus design).
- All asset paths updated to be served correctly by Vite dev server (`/ui_design/css/`, `/ui_design/js/`).
- Database page nav link updated to `/ui_design/designs/design-03-database-v1.html`.

### English UI Migration (Dashboard — `index.html`)
- Navigation: Dashboard, Reports, Database, Settings.
- Section headers: WHAT'S NEW?, ACTIVE ORDERS.
- Table column headers: Customer Name, Identifier, Status, Workflow.
- Stat boxes: Active Orders, Closed in 30 days.
- Theme toggle label: Dark Mode / Light Mode.
- Modal titles: Full Update History, Summary, Detailed Description.
- Details panel sections: Products, Documents, History, Total.
- Action badge: Processed.
- Placeholders: Ask P.I.S.T.A...., Filter (Customer, Status...), Ask....
- Empty state: Click an order to see its details!
- `lang` attribute: `en`.

### Bug Fix
- `dataService.getOrderDetails()` catch block now falls back to mock data instead of returning `order: null`, preventing silent failures in the details panel.

### Documentation
- `docs/designs/ui_descriptions.md`: Removed last Hungarian term ("Részletek" → "Details").
- `SOLUTION_DESIGN.md`: Version bumped to v0.5.2, `index.html` added to Component Responsibility Matrix.

## Language Policy
- **UI scaffolding** (labels, headers, buttons, placeholders): English.
- **Business data** (customer names, product names, order notes, AI chat): Hungarian.
