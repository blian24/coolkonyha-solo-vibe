## What's New

### Settings View (full implementation)

The Settings route previously showed a stub placeholder. It is now a fully functional view integrated into the SPA router.

**General Section:**
- Theme toggle — switches between Dark and Light mode (wired to existing `toggleTheme()`)
- Language selector — placeholder control for future i18n support
- Sidebar width reset — restores sidebar to default 18vw width

**Admin Section:**
- System information card — displays app version, environment, stack
- Clear Logs button — clears client-side session logs with toast feedback
- Feature Flags table — read-only overview of planned and active features

### New Shared UI Primitives (oceanic-plus.css)

The following reusable CSS classes were added to the design system:

| Class | Purpose |
|-------|---------|
| `.settings-tab-bar` / `.settings-tab-btn` | Tab navigation |
| `.settings-section` | Collapsible content panels |
| `.settings-row` / `.settings-row-info` | Setting row layout |
| `.settings-label` / `.settings-desc` | Typography |
| `.settings-divider` | Section separator headings |
| `.settings-select` / `.settings-btn` | Form controls |
| `.settings-info-card` / `.settings-info-row` | Admin info display |
| `.feature-flag-table` | Admin feature flags table |
| `.toggle-switch` | Reusable toggle input |
| `.toast-notification` | Global toast feedback |

## Known Limitations

- Admin section is visible to all users (no auth gate — deferred to future auth layer implementation)
- Language selector is visual-only (i18n not implemented)
- Feature flags are read-only toggles (no backend wiring)
