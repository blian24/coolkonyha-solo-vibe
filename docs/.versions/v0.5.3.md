# Release Notes — v0.5.3

**Date:** 2026-05-25
**Type:** Bug Fixes / UI Stability

## Summary

This release addresses all 6 major issues identified in the client-side single-page application (SPA), fixing database loading states, scope resolution errors, routing placeholder states, stat box calculations, and translation values.

## Changes

### Bug Fixes

#### 1. Database Tab Loading Fix (BUG-01)
* **File:** [databaseController.js](file:///d:/dev/coolkonyha-solo-vibe/ui_design/js/controllers/databaseController.js)
* **Fix:** Initialized `currentTab` to `null` (instead of `'customers'`). This ensures the bootstrap `switchTab('customers')` call runs fully and fetches the initial dataset rather than getting blocked by the tab guard.

#### 2. Swapped Fallback Handlers (BUG-02)
* **File:** [databaseController.js](file:///d:/dev/coolkonyha-solo-vibe/ui_design/js/controllers/databaseController.js)
* **Fix:** Swapped the offline fallback handlers in `prefetchOrders` and `initDatabaseController`. Now, `prefetchOrders` falls back to mock orders, and `initDatabaseController` falls back to mock customers correctly.

#### 3. dataService Scope Resolution (BUG-03)
* **File:** [dashboardController.js](file:///d:/dev/coolkonyha-solo-vibe/ui_design/js/controllers/dashboardController.js)
* **Fix:** Replaced bare `dataService` calls with explicit `window.dataService` scope references, resolving runtime ReferenceErrors in ES modules / strict-mode environments when using the filter input box.

#### 4. Reports & Settings Route Navigation (BUG-04)
* **Files:** [router.js](file:///d:/dev/coolkonyha-solo-vibe/ui_design/js/router.js), [reports.html](file:///d:/dev/coolkonyha-solo-vibe/ui_design/views/reports.html), [settings.html](file:///d:/dev/coolkonyha-solo-vibe/ui_design/views/settings.html)
* **Fix:** Enabled and bound the `reports` and `settings` URL hash routes. Created corresponding view files with styled glassmorphism ice-cards explaining that these panels are currently under development.

#### 5. Live Dashboard Stat Counters (BUG-05)
* **Files:** [dashboardController.js](file:///d:/dev/coolkonyha-solo-vibe/ui_design/js/controllers/dashboardController.js), [dashboard.html](file:///d:/dev/coolkonyha-solo-vibe/ui_design/views/dashboard.html)
* **Fix:** Added dynamic HTML element IDs and connected them to live filters. The dashboard now calculates and renders "Active Orders" (excluding closed/cancelled) and "Closed in 30 days" dynamically from `dataService` instead of showing hardcoded placeholders (`124` and `210`).

#### 6. Dynamic Hungarian UI Translation (BUG-06)
* **File:** [dataService.js](file:///d:/dev/coolkonyha-solo-vibe/ui_design/js/services/dataService.js)
* **Fix:** Localized UI-level string outputs inside the `getUpdates()` helper. The title now prefixes `"Order Update: "` (instead of Hungarian *"Rendelés Frissítés: "*) and the suggestion defaults to `"Order in progress."` (instead of *"Rendelés folyamatban."*).

## Verification
* All fixes have been verified using a local Vite environment (`npm run dev`) and Express API (`node server/index.js`).
* Verification comments documenting exact browser observations and screenshots have been posted to each related ClickUp ticket.
