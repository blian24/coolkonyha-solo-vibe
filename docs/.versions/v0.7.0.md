## What's New

### Comprehensive Database Viewer
Enhanced the database viewer menu item to show all database tables and all data. The viewer now displays always up-to-date data. Extended the database viewer from 5 tabs to 13 tabs grouped across 4 logical domains. Added a Refresh button to the header.

**Tab Groups:**
*   **Master Data:** Customers, Suppliers, Products
*   **Orders:** Orders, Order Items, Order History, Order Workflow
*   **Maintenance:** Cases, Items, History, Maintenance Workflow
*   **Email & AI:** Processed Emails, Sender Rules

### Backend Updates
*   **`server/agent.js`**: Added 6 new methods: `getAllOrderItems`, `getOrderStatusHistory`, `getAllMaintenanceItems`, `getAllMaintenanceHistory`, `getProcessedEmails`, `getSenderRules`.
*   **`server/routes.js`**: Added 6 new endpoints: `GET /api/order-items`, `/api/order-history`, `/api/maintenance-items`, `/api/maintenance-history`, `/api/processed-emails`, `/api/sender-rules`.

### Frontend Updates
*   **`ui_design/views/database.html`**: Replaced the 5-tab bar with a grouped 13-tab layout (4 groups) and added a Refresh button.
*   **`ui_design/js/controllers/databaseController.js`**: Full rewrite; added renderers for all 13 tables, `TAB_ENDPOINTS` map, and `refreshCurrentTab()`.
*   **`ui_design/css/oceanic-plus.css`**: Added `.db-tab-group-label` style.
